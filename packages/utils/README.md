# @eosjs/utils

Utility functions for Eos Web Components library.

## 📦 Installation

```bash
npm install @eosjs/utils
# or
pnpm add @eosjs/utils
# or
yarn add @eosjs/utils
```

```typescript
import { /* utility functions */ } from '@eosjs/utils';
```
