## Introduction

Button is a framework-agnostic Web Component aligned with the EOS semantic color and sizing system. It works with React, Vue, Angular, and plain HTML without a framework adapter.

## Variants

Button supports semantic colors, visual variants, three sizes, loading, disabled, and icon-only states.

## API

### Attributes

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `color` | `default \| primary \| secondary \| success \| warning \| danger` | `primary` | 语义颜色 |
| `variant` | `solid \| bordered \| light \| flat \| ghost \| primary \| secondary \| tertiary \| outline \| danger \| dangerSoft` | `solid` | 视觉变体 |
| `size` | `sm \| md \| lg` | `md` | 按钮尺寸，分别为 32/36/40px 高 |
| `disabled` | `boolean` | `false` | 禁用按钮 |
| `loading` | `boolean` | `false` | 显示加载状态并阻止点击 |
| `icon-only` | `boolean` | `false` | 使用 32/36/40px 正方形按钮 |
| `full-width` | `boolean` | `false` | 按钮占满宿主宽度 |
| `type` | `button \| submit \| reset` | `button` | 原生按钮类型 |
| `aria-label` | `string` | - | icon-only 按钮的可访问名称 |

### Events

| 事件名 | 触发时机 | 事件对象 |
| --- | --- | --- |
| `click` | 按钮点击 | 原生 `MouseEvent` |

### Slots

图标通过命名插槽传入，组件不会绑定任何框架图标实现：

```html
<eos-button>
  <svg slot="start" viewBox="0 0 16 16" aria-hidden="true"><!-- icon --></svg>
  Save
  <svg slot="end" viewBox="0 0 16 16" aria-hidden="true"><!-- icon --></svg>
</eos-button>

<eos-button icon-only aria-label="Settings">
  <svg slot="start" viewBox="0 0 16 16" aria-hidden="true"><!-- icon --></svg>
</eos-button>
```

### Framework integration

#### React

```tsx
import { useEffect, useRef } from 'react';
import '@eosjs/components';

export function MyButton() {
  const ref = useRef<HTMLElement>(null);

  useEffect(() => {
    const element = ref.current;
    const onClick = (event: Event) => {
      console.log('clicked:', event.type);
    };
    element?.addEventListener('click', onClick);
    return () => element?.removeEventListener('click', onClick);
  }, []);

  return <eos-button ref={ref}>Click me</eos-button>;
}
```

#### Vue 3

```vue
<template>
  <eos-button @click="handleClick">Click me</eos-button>
</template>

<script setup>
import '@eosjs/components';

function handleClick(event) {
  console.log('clicked:', event.type);
}
</script>
```

#### Angular

```ts
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import '@eosjs/components';

@Component({
  selector: 'app-button',
  template: '<eos-button (click)="onClick($event)">Click me</eos-button>',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
})
export class ButtonComponent {
  onClick(event: MouseEvent) {
    console.log('clicked:', event.type);
  }
}
```

#### 原生 HTML

```html
<script type="module">
  import '@eosjs/components';
  document.querySelector('eos-button').addEventListener('click', (event) => {
    console.log('clicked:', event.type);
  });
</script>

<eos-button>Click me</eos-button>
```

### CSS custom properties

组件默认使用 EOS 的语义变量。应用只需要在主题根节点或 `eos-button` 宿主上提供同名变量，即可切换 Light/Dark 值；组件内部只保留组件级别的别名，不要求应用了解 Shadow DOM 实现。

```css
/* 主题层：建议集中放在应用的 :root / [data-theme] 中 */
:root {
  /* Figma semantic tokens: slash is represented by a hyphen in CSS. */
  --accent-accent: #006fee;
  --accent-accent-foreground: #fcfcfc;
  --accent-accent-hover: #3592f9;
  --default-default: #ebebec;
  --default-default-foreground: #18181b;
  --surface-surface-secondary: #efeff0;
  --border: #dedee0;
  --focus-ring: #006fee;
}
```
