## Introduction

ProgressBar 用于展示多步骤流程、轮播进度或可点击的分段导航。它支持横向和纵向布局，也可以通过 DOM 方法控制动画。

## Basic Usage

<Demo of={Basic} title="可点击的分段进度" />

```html
<eos-progress-bar total="4" current="1" variant="tiktok"></eos-progress-bar>
```

## 变体

```html
<eos-progress-bar total="4" current="1" variant="default"></eos-progress-bar>
<eos-progress-bar total="4" current="1" variant="dots"></eos-progress-bar>
<eos-progress-bar total="4" current="1" variant="tiktok"></eos-progress-bar>
```

## 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `total` | `number` | `0` | 总段数 |
| `current` | `number` | `0` | 当前段索引，从 `0` 开始 |
| `variant` | `default \| dots \| tiktok` | `default` | 指示器样式 |
| `position` | `top \| bottom \| left \| right` | `bottom` | 指示器方向 |
| `loading` | `boolean` | `false` | 当前段显示加载波纹 |

## 方法

```ts
const progress = document.querySelector('eos-progress-bar');

progress.startProgress({
  duration: 3000,
  onComplete: () => console.log('segment complete'),
});
progress.setProgress(45);
progress.setLoading(true);
progress.stopProgress();
```

## 事件

| 事件名 | 触发时机 | `event.detail` |
| --- | --- | --- |
| `segment-click` | 点击某一段 | `{ index }` |

## CSS 自定义属性

| 变量 | 说明 |
| --- | --- |
| `--progress-bar-height` | 默认进度条高度 |
| `--progress-bar-gap` | 分段间距 |
| `--progress-bar-color` | 未完成段颜色 |
| `--progress-bar-active-color` | 已完成段和当前进度颜色 |
