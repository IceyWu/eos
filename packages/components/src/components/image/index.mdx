## Introduction

Image 是一个面向 Web Components 的图片组件。除了标准图片属性，它还提供懒加载、BlurHash 占位、渐进式加载和加载事件。

## Basic Usage

<Demo of={Basic} title="基础用法" />

```html
<eos-image
  src="https://example.com/cover.jpg"
  alt="Cover"
  loading="lazy"
  object-fit="cover"
  style="width: 520px; height: 220px"
></eos-image>
```

## 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | — | 图片 URL，或 BlurHash 字符串 |
| `src-type` | `url \| blurhash` | `url` | 指定 `src` 的类型 |
| `alt` | `string` | — | 图片替代文本 |
| `width` / `height` | `string` | — | 图片尺寸 |
| `loading` | `lazy \| eager` | — | 是否使用懒加载 |
| `crossorigin` | `string` | — | 跨域设置 |
| `object-fit` | `cover \| contain \| fill \| none \| scale-down` | — | 图片填充方式 |
| `placeholder` | `string` | — | 占位 URL 或 BlurHash |
| `placeholder-type` | `url \| blurhash` | `url` | 指定占位内容类型 |
| `placeholder-fill` | `boolean` | `false` | 占位图作为背景层显示 |
| `show-delay` | `string` | `0` | 图片加载成功后的显示延迟，单位毫秒 |

## BlurHash 占位

```html
<eos-image
  src="https://example.com/cover.jpg"
  placeholder="LEHV6nWB2yk8pyo0adR*.7kCMdnj"
  placeholder-type="blurhash"
  placeholder-fill
  style="width: 320px; height: 200px"
></eos-image>
```

## 事件

| 事件名 | 触发时机 | `event.detail` |
| --- | --- | --- |
| `imageLoad` | 图片加载成功 | — |
| `imageError` | 图片加载失败 | — |
| `imageProgress` | 图片加载过程中 | `{ loaded, total }` |

## 加载插槽

```html
<eos-image src="/cover.jpg" style="width: 320px; height: 200px">
  <span slot="loading">Preparing image…</span>
  <span slot="error">Try again later</span>
</eos-image>
```
