## Introduction

Carousel 是一个支持自动播放、循环模式、触摸滑动和键盘导航的 Web Component 轮播图。

## 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `autoplay` | `boolean` | `false` | 自动播放 |
| `interval` | `number` | `3000` | 自动播放间隔（毫秒） |
| `loop` | `boolean` | `false` | 循环模式 |
| `show-navigation` | `boolean` | `true` | 显示导航箭头 |
| `initial-index` | `number` | `0` | 初始幻灯片索引 |
| `indicator-position` | `top \| bottom \| left \| right` | `bottom` | 指示器位置 |
| `indicator-style` | `default \| dots \| tiktok` | `default` | 指示器样式 |

## 事件

| 事件名 | 触发时机 | `event.detail` |
| --- | --- | --- |
| `change` | 切换幻灯片 | `{ currentIndex, previousIndex }` |
| `slide-click` | 点击幻灯片 | `{ index }` |

## 组件方法

可以通过 DOM 引用控制轮播图：

```ts
const carousel = document.querySelector('eos-carousel');

carousel.play();
carousel.pause();
carousel.next();
carousel.prev();
carousel.goTo(2);
```

## CSS 自定义属性

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `--carousel-height` | `400px` | 轮播图高度 |
| `--progress-bar-color` | `#e0e0e0` | 进度条背景色 |
| `--progress-bar-active-color` | `#007bff` | 进度条激活色 |
| `--control-bg` | `rgba(0,0,0,0.5)` | 导航按钮背景 |
| `--dot-size` | `8px` | dots 模式下的圆点大小 |

## 框架集成

组件使用标准 DOM 属性和 CustomEvent，因此同一套标签可以直接用于 React、Vue、Angular 和原生 HTML。

```html
<eos-carousel autoplay loop interval="3000">
  <div>幻灯片 1</div>
  <div>幻灯片 2</div>
</eos-carousel>
```
