🎨 Eos Components 使用示例

📦 安装方法

方法 1: 通过 npm 安装（推荐）

npm install @eosjs/components
pnpm add @eosjs/components

方法 2: 本地引用（开发调试）

npm install file:../../packages/components

方法 3: 直接引入 ES Module（纯 HTML）

<script type="module"> import { registerComponents } from './node_modules/@eosjs/components/dist/index.js'; registerComponents(); </script>

🔘 Button 按钮组件

基础用法

默认按钮
<eos-button>默认按钮</eos-button>

不同类型的按钮

主要按钮 次要按钮 成功按钮 危险按钮 警告按钮 信息按钮
<eos-button variant="primary">主要按钮</eos-button> <eos-button variant="secondary">次要按钮</eos-button> <eos-button variant="success">成功按钮</eos-button> <eos-button variant="danger">危险按钮</eos-button>

不同尺寸的按钮

小按钮 中等按钮 大按钮
<eos-button size="small">小按钮</eos-button> <eos-button size="medium">中等按钮</eos-button> <eos-button size="large">大按钮</eos-button>

禁用状态

禁用按钮 禁用主要按钮
<eos-button disabled>禁用按钮</eos-button>

点击事件示例

点击我
<eos-button id="clickBtn">点击我</eos-button> <script> document.getElementById('clickBtn').addEventListener('click', () => { alert('按钮被点击了！'); }); </script>

🎠 Carousel 轮播图组件

基础轮播图

幻灯片 1
幻灯片 2
幻灯片 3
<eos-carousel autoplay interval="3000"> <div style="background: #667eea; height: 300px;">幻灯片 1</div> <div style="background: #f5576c; height: 300px;">幻灯片 2</div> <div style="background: #00f2fe; height: 300px;">幻灯片 3</div> </eos-carousel>

可配置的轮播图

🎨 图片 1
🚀 图片 2
🌟 图片 3
<eos-carousel autoplay interval="5000" show-arrows show-dots> <div>图片 1</div> <div>图片 2</div> <div>图片 3</div> </eos-carousel>

📖 使用说明

提示： Eos Components 基于 Web Components 技术构建，可以在任何前端框架中使用，包括原生 HTML、React、Vue、Angular 等。

完整的 HTML 文件示例

<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Eos Components Demo</title> </head> <body> <h1>我的应用</h1> <!-- 使用按钮组件 --> <eos-button variant="primary">点击我</eos-button> <!-- 使用轮播图组件 --> <eos-carousel autoplay> <div>幻灯片 1</div> <div>幻灯片 2</div> </eos-carousel> <!-- 引入组件库 --> <script type="module"> import { registerComponents } from '@eosjs/components'; registerComponents(); </script> </body> </html>
✅ 成功提示： 如果你能看到上面的组件正常显示，说明 Eos Components 已经成功加载！
