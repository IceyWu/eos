# Quick Start Guide

Get started with Eos Web Components in minutes.

## Installation

Choose your preferred package manager:

```bash
npm install @eosjs/components
```

```bash
yarn add @eosjs/components
```

```bash
pnpm add @eosjs/components
```

## Framework Integration

### React

**1. Import the library**

```jsx
import '@eosjs/components';
```

**2. Use components in JSX**

```jsx
function App() {
  const buttonRef = useRef(null);
  
  useEffect(() => {
    const button = buttonRef.current;
    button?.addEventListener('e-click', (e) => {
      console.log('Clicked:', e.detail);
    });
  }, []);
  
  return <e-button ref={buttonRef}>Click me</e-button>;
}
```

**3. TypeScript support (optional)**

Create `web-components.d.ts`:

```typescript
declare namespace JSX {
  interface IntrinsicElements {
    'e-button': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement>, HTMLElement>;
    'e-carousel': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement> & {
      autoplay?: boolean;
      interval?: number;
      loop?: boolean;
    }, HTMLElement>;
  }
}
```

### Vue 3

**1. Import in main.js or component**

```javascript
import '@eosjs/components';
```

**2. Use in templates**

```vue
<template>
  <e-button @e-click="handleClick">Click me</e-button>
  <e-carousel autoplay loop :interval="3000">
    <div>Slide 1</div>
    <div>Slide 2</div>
  </e-carousel>
</template>

<script setup>
const handleClick = (e) => {
  console.log('Clicked:', e.detail);
};
</script>
```

### Angular

**1. Import in component**

```typescript
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import '@eosjs/components';

@Component({
  selector: 'app-root',
  template: `
    <e-button>Click me</e-button>
    <e-carousel autoplay loop [attr.interval]="3000">
      <div>Slide 1</div>
      <div>Slide 2</div>
    </e-carousel>
  `,
  schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppComponent {}
```

**2. Handle events**

```typescript
ngOnInit() {
  const button = document.querySelector('e-button');
  button?.addEventListener('e-click', (e: Event) => {
    const customEvent = e as CustomEvent;
    console.log('Clicked:', customEvent.detail);
  });
}
```

### Vanilla JavaScript

```html
<!DOCTYPE html>
<html>
<head>
  <script type="module">
    import '@eosjs/components';
    
    document.querySelector('e-button').addEventListener('e-click', (e) => {
      console.log('Clicked:', e.detail);
    });
  </script>
</head>
<body>
  <e-button>Click me</e-button>
  <e-carousel autoplay loop interval="3000">
    <div>Slide 1</div>
    <div>Slide 2</div>
  </e-carousel>
</body>
</html>
```

## Component Methods

Access component methods via DOM reference:

```javascript
const carousel = document.querySelector('e-carousel');

// Control playback
carousel.play();
carousel.pause();

// Navigate
carousel.next();
carousel.prev();
carousel.goTo(2);
```

## Event Handling

All components emit custom events:

```javascript
// Button events
button.addEventListener('e-click', (e) => {
  console.log(e.detail.message);
});

// Carousel events
carousel.addEventListener('change', (e) => {
  console.log('Current:', e.detail.currentIndex);
  console.log('Previous:', e.detail.previousIndex);
});

carousel.addEventListener('slide-click', (e) => {
  console.log('Clicked slide:', e.detail.index);
});
```

## Styling

Customize components with CSS variables:

```css
e-carousel {
  --carousel-height: 500px;
  --progress-bar-color: rgba(0, 0, 0, 0.2);
  --progress-bar-active-color: #007bff;
  --control-bg: rgba(0, 0, 0, 0.5);
}

e-button {
  --button-bg: #007bff;
  --button-color: white;
}
```
