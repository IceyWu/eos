# 快速开始指南

几分钟内快速上手 Eos Web Components。

## 安装

选择你喜欢的包管理器：

```bash
npm install @eosjs/components
```

```bash
yarn add @eosjs/components
```

```bash
pnpm add @eosjs/components
```

## 框架集成

### React

**1. 导入库**

```jsx
import '@eosjs/components';
```

**2. 在 JSX 中使用组件**

```jsx
function App() {
  const buttonRef = useRef(null);
  
  useEffect(() => {
    const button = buttonRef.current;
    button?.addEventListener('e-click', (e) => {
      console.log('点击了:', e.detail);
    });
  }, []);
  
  return <eos-button ref={buttonRef}>点击我</eos-button>;
}
```

**3. TypeScript 支持（可选）**

创建 `web-components.d.ts`：

```typescript
declare namespace JSX {
  interface IntrinsicElements {
    'eos-button': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement>, HTMLElement>;
    'eos-carousel': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement> & {
      autoplay?: boolean;
      interval?: number;
      loop?: boolean;
    }, HTMLElement>;
  }
}
```

### Vue 3

**1. 在 main.js 或组件中导入**

```javascript
import '@eosjs/components';
```

**2. 在模板中使用**

```vue
<template>
  <eos-button @e-click="handleClick">点击我</eos-button>
  <eos-carousel autoplay loop :interval="3000">
    <div>幻灯片 1</div>
    <div>幻灯片 2</div>
  </eos-carousel>
</template>

<script setup>
const handleClick = (e) => {
  console.log('点击了:', e.detail);
};
</script>
```

### Angular

**1. 在组件中导入**

```typescript
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import '@eosjs/components';

@Component({
  selector: 'app-root',
  template: `
    <eos-button>点击我</eos-button>
    <eos-carousel autoplay loop [attr.interval]="3000">
      <div>幻灯片 1</div>
      <div>幻灯片 2</div>
    </eos-carousel>
  `,
  schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppComponent {}
```

**2. 处理事件**

```typescript
ngOnInit() {
  const button = document.querySelector('eos-button');
  button?.addEventListener('e-click', (e: Event) => {
    const customEvent = e as CustomEvent;
    console.log('点击了:', customEvent.detail);
  });
}
```

### 原生 JavaScript

```html
<!DOCTYPE html>
<html>
<head>
  <script type="module">
    import '@eosjs/components';
    
    document.querySelector('eos-button').addEventListener('e-click', (e) => {
      console.log('点击了:', e.detail);
    });
  </script>
</head>
<body>
  <eos-button>点击我</eos-button>
  <eos-carousel autoplay loop interval="3000">
    <div>幻灯片 1</div>
    <div>幻灯片 2</div>
  </eos-carousel>
</body>
</html>
```

## 组件方法

通过 DOM 引用访问组件方法：

```javascript
const carousel = document.querySelector('eos-carousel');

// 控制播放
carousel.play();
carousel.pause();

// 导航
carousel.next();
carousel.prev();
carousel.goTo(2);
```

## 事件处理

所有组件都会触发自定义事件：

```javascript
// 按钮事件
button.addEventListener('e-click', (e) => {
  console.log(e.detail.message);
});

// 轮播事件
carousel.addEventListener('change', (e) => {
  console.log('当前:', e.detail.currentIndex);
  console.log('上一个:', e.detail.previousIndex);
});

carousel.addEventListener('slide-click', (e) => {
  console.log('点击了幻灯片:', e.detail.index);
});
```

## 样式定制

使用 CSS 变量自定义组件：

```css
eos-carousel {
  --carousel-height: 500px;
  --progress-bar-color: rgba(0, 0, 0, 0.2);
  --progress-bar-active-color: #007bff;
  --control-bg: rgba(0, 0, 0, 0.5);
}

eos-button {
  --button-bg: #007bff;
  --button-color: white;
}
```
