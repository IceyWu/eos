<a href="/zh/skills.md" target="_blank" rel="noreferrer">skills.md 原始文件</a>为编码 Agent 提供了使用 EOS UI 的简要工作流程。

## 推荐流程

1. 在 [LLM 文档索引](/zh/llms.txt) 中查找组件。
2. 阅读组件 Markdown 参考，确认属性、事件、方法和示例。
3. 导入组件前先查看[快速开始](/zh/docs/getting-started)。
4. 使用 EOS 语义令牌，并同时支持 Light 和 Dark 主题。
5. 支持键盘操作，并尊重系统的减少动态效果设置。

需要完整 API 时使用 <a href="/zh/llms-full.txt" target="_blank" rel="noreferrer">llms-full.txt</a>。
