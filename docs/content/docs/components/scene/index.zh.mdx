## 基础用法

`eos-scene` 提供内容区域，并为内部的 `eos-scene-item` 提供共享坐标系。定位项可以插入任意内容，例如标记、标签、说明卡片或遮罩。

<Demo id="components-scene-demos-index" of={Basic} source={BasicSource} title="场景与多个叠加项" layout="center" />

点击标记打开详情卡片，再次点击收起。示例复用了图片组件文档中的理塘风景图。使用场景上方的 `+`、`−` 缩放外部容器，也可以直接拖动图片移动容器，观察标记是否仍贴合原图片坐标。

## 坐标与容器尺寸

`x` 和 `y` 是 0 到 1 之间的比例坐标，原点位于场景左上角。坐标相对场景内容区域计算，因此场景或父容器移动、尺寸变化后，定位项仍对应同一个比例位置；它们不依赖页面或视口坐标。示例控件只变换 `eos-scene` 外部的容器，组件本身只提供坐标空间。

定位到图片上时，应让场景宽高比与图片内容一致，避免 `object-fit: cover` 裁切影响坐标映射。`anchor` 决定定位项的哪个边、角或中心与坐标重合；重叠时可用 `z-index` 控制层级。

## 属性

### `eos-scene`

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `aria-label` | string | `场景内容` | 场景内容的可访问名称 |

也可通过 `--eos-scene-aspect-ratio` 设置宽高比（默认 `16 / 9`），通过 `--eos-scene-radius` 设置圆角（默认 `16px`）。

### `eos-scene-item`

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` / `y` | number | `0.5` | 0 到 1 之间的场景比例坐标 |
| `anchor` | `center \| top-left \| top \| top-right \| right \| bottom-right \| bottom \| bottom-left \| left` | `center` | 与坐标重合的边、角或中心 |
| `z-index` | number | `1` | 定位项的叠放顺序 |

定位项内按钮、链接等内容保留原生事件名称和事件对象。
