EOS 组件是可跨框架使用的自定义元素。每篇组件文档都包含实时示例，以及应用可使用的公开 API。

## 通用

- [Button](/zh/docs/components/button)：提供语义变体、事件和 CSS 变量主题的操作按钮。
- [Select](/zh/docs/components/select)：支持搜索、四向定位和虚拟化选项的选择器。

## 数据展示

- [Card Stack](/zh/docs/components/card-stack)：支持手势操作和可逆过渡的卡片堆栈。
- [Carousel](/zh/docs/components/carousel)：支持指示器、触摸手势和可选自动播放的内容导航。
- [Image](/zh/docs/components/image)：支持响应式媒体、懒加载、BlurHash 和加载状态。
- [Image Group](/zh/docs/components/image-group)：以紧凑布局展示相关图片集合。
- [Scene](/zh/docs/components/scene)：为定位遮罩和交互点提供坐标空间。
- [Scrollbar](/zh/docs/components/scrollbar)：可附加到现有滚动容器的自定义滚动条。

## 反馈

- [Progress Bar](/zh/docs/components/progress-bar)：用于步骤、加载和导航的分段进度指示器。
