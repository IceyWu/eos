## 介绍

图片是支持响应式媒体的 Web Component，并提供延迟加载、BlurHash 占位图、加载反馈和明确的回退状态。

## 响应式和圆形图片

`responsive` 让图片跟随可用宽度，`circle` 将图片裁剪为圆形并保留声明尺寸。

## API

<Api name="Image" />

### 属性

图片支持 `src`、`src-type`、`alt`、`width`、`height`、`loading`、`placeholder`、`placeholder-type`、`placeholder-fill`、`responsive` 和 `circle` 属性。

### 事件

`load` 和 `error` 使用原生事件名，`progress` 用于报告网络加载进度。

### 插槽

使用 `loading` 和 `error` 插槽提供自定义状态内容。
