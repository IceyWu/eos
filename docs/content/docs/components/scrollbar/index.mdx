## Introduction

Scrollbar provides a consistent custom track and thumb for horizontal or vertical scrolling. Attach it to a native scroll container to keep the thumb synchronized, or drive it manually for virtualized content.

## API

### Attributes

| Attribute | Type | Default | Description |
| --- | --- | --- | --- |
| `direction` | `horizontal \| vertical` | `horizontal` | Scroll direction |
| `auto-hide` | `boolean` | `false` | Fade out when the scrollbar is idle |
| `thumb-color` | `string` | `var(--eos-color-foreground-muted)` | Thumb color |
| `track-color` | `string` | `var(--eos-color-border)` | Track color |
| `thumb-size` | `string` | `6` | Thumb thickness in pixels |
| `thumb-min-size` | `string` | `30` | Minimum thumb length in pixels |
| `border-radius` | `string` | `3` | Track and thumb radius in pixels |

### Methods

| Method | Description |
| --- | --- |
| `attach(element)` | Bind to a scrollable element |
| `detach()` | Remove the current binding |
| `setVirtualScroll(options)` | Set a virtual content size, viewport size, and offset |
| `clearVirtualScroll()` | Return to DOM-driven scrolling |

```ts
const scrollbar = document.querySelector('eos-scrollbar');

scrollbar.setVirtualScroll({
  contentSize: 100000,
  viewportSize: 600,
  scrollOffset: 1200,
});
```

### Events

| Event | When it fires | `event.detail` |
| --- | --- | --- |
| `scroll-change` | The scroll position changes | `{ position, ratio, scrollOffset? }` |

### Slots

Scrollbar has no content slots. Place it adjacent to the scroll container it controls and call `attach(element)` after both elements are connected.
