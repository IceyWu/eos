## 介绍

滚动条提供一致的水平或垂直轨道和滑块，可与原生滚动容器同步，也可以为虚拟化内容手动驱动。

### 属性

滚动条支持方向、滚动比例和拖拽相关配置。

### 方法

使用 `attach(element)` 将滚动条连接到滚动容器，也可以通过命令式方法更新位置。

### 事件

滚动条会在拖拽、滚动和位置变化时发出事件。

### 插槽

滚动条没有内容插槽，应将它放置在被控制的滚动容器旁边。
