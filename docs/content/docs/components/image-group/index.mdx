## Image Group

Use the image group for related images that belong to one visual collection. It delegates image rendering to eos-image while the group controls layout, focus, and count overflow.
The `grid` and `pair` layouts keep tiles square based on the rendered row count and center an incomplete last row. An empty group takes no layout space.
The default tile gap is 4px and the corner radius is 5px. Customize them with `--eos-image-group-gap` and `--eos-image-group-radius`.
