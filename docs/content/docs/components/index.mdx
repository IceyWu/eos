EOS components are framework-agnostic custom elements. Each reference includes live examples and the public API available to your application.

## General

- [Button](/docs/components/button): actions with semantic variants, events, and CSS variable theming.
- [Select](/docs/components/select): searchable selection with four-side placement and virtualized options.

## Data display

- [Card Stack](/docs/components/card-stack): swipeable cards with reversible pointer-driven transitions.
- [Carousel](/docs/components/carousel): content navigation with indicators, touch gestures, and optional autoplay.
- [Image](/docs/components/image): responsive media with lazy loading, BlurHash, and loading states.
- [Image Group](/docs/components/image-group): compact, responsive collections of related images.
- [Scene](/docs/components/scene): a coordinate space for positioned overlays and interactive points.
- [Scrollbar](/docs/components/scrollbar): a custom scrollbar that can attach to an existing scroll container.

## Feedback

- [Progress Bar](/docs/components/progress-bar): segmented progress for steps, loading, and navigation.
