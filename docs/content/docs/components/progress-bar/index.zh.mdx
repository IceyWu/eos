## 介绍

进度条表示有限数量分段中的当前进度，支持水平和垂直方向、三种视觉变体、可点击分段和命令式动画。

### 属性

属性包括分段数量、当前进度、方向、视觉变体和是否允许点击。

### 方法

元素提供用于更新和动画化进度的方法。

### 事件

点击分段或进度变化时会发出结构化事件。
