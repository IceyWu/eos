## 安装

使用你习惯的包管理器安装：

```bash
npm install @eosjs/ui
yarn add @eosjs/ui
pnpm add @eosjs/ui
```

## 按需导入

推荐按页面导入所需组件，自动注册对应元素，并导出组件类和公共类型：

```ts
import '@eosjs/ui/button';
import '@eosjs/ui/image';
import '@eosjs/ui/carousel';
import type { EosImageGroupItem } from '@eosjs/ui/image-group';
import type { CardStackRenderer } from '@eosjs/ui/card-stack';
```

| 入口 | 自动注册 |
| --- | --- |
| `@eosjs/ui/button` | Button |
| `@eosjs/ui/card-stack` | CardStack |
| `@eosjs/ui/carousel` | Carousel、ProgressBar |
| `@eosjs/ui/image` | Image |
| `@eosjs/ui/image-group` | ImageGroup、Image |
| `@eosjs/ui/progress-bar` | ProgressBar |
| `@eosjs/ui/scrollbar` | Scrollbar |

Carousel、ImageGroup 自动注册内部依赖；插槽中的其他组件仍需调用方导入。重复导入或与总入口混用不会重复注册。`@eosjs/ui/config` 仅导出配置，不加载组件。

`import '@eosjs/ui'` 保持兼容并注册全部组件。`import type` 不触发运行时注册，`@eosjs/ui/jsx-types` 保持不变。所有运行时入口可在无浏览器环境中导入；创建和渲染元素仍在客户端执行。

> 按需入口尚未发布，目前请使用构建后的本地链接包。现有 npm 版本不包含这些新入口。

## 框架集成

EOS 自定义元素可以直接用于 React、Vue、Angular 和原生 HTML。

### React

```tsx
import '@eosjs/ui';

export function App() {
  return <eos-button>开始使用</eos-button>;
}
```

### Vue 3

```vue
<template><eos-button>开始使用</eos-button></template>
<script setup>import '@eosjs/ui';</script>
```

### Angular

在 Angular 中启用 `CUSTOM_ELEMENTS_SCHEMA`，然后像普通元素一样使用 EOS 组件。

### 原生 HTML

```html
<script type="module">
  import '@eosjs/ui';
</script>
<eos-button>开始使用</eos-button>
```

## 组件方法与事件

组件使用原生 DOM 事件，并通过元素方法提供命令式控制。

## 样式

组件消费 EOS 语义变量，并同时支持 Light 和 Dark 主题。
