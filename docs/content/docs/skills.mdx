## Recommended workflow

1. Find a component in the [LLM documentation index](/llms.txt).
2. Read its Markdown reference for attributes, events, methods, and examples.
3. Check the [getting started guide](/docs/getting-started) before importing components.
4. Use EOS semantic tokens and support both Light and Dark themes.
5. Respect keyboard access and reduced-motion preferences.

Use [llms.txt](/llms.txt) for the component index or <a href="/llms-full.txt?view=browser" target="_blank" rel="noreferrer">llms-full.txt</a> when you need all references together.
