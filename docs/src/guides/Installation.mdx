# 安装指南

> 详细的安装和配置说明

## 📋 系统要求

### 环境要求

- **Node.js** >= 18.0.0
- **现代浏览器** 支持 ES2020+ 和 Web Components

### 浏览器兼容性

| 浏览器 | 最低版本 | 推荐版本 | 备注 |
|--------|----------|----------|------|
| Chrome | 88+ | 最新版 | ✅ 完全支持 |
| Firefox | 85+ | 最新版 | ✅ 完全支持 |
| Safari | 14+ | 最新版 | ✅ 完全支持 |
| Edge | 88+ | 最新版 | ✅ 完全支持 |

## 📦 安装方式

### 方式一：包管理器安装（推荐）

#### npm

```bash
npm install @eosjs/components
```

#### pnpm（推荐）

```bash
pnpm add @eosjs/components
```

#### yarn

```bash
yarn add @eosjs/components
```

### 方式二：CDN 引入

#### jsDelivr CDN

```html
<!-- 最新版本 -->
<script type="module" src="https://cdn.jsdelivr.net/npm/@eosjs/components/dist/index.js"></script>

<!-- 指定版本 -->
<script type="module" src="https://cdn.jsdelivr.net/npm/@eosjs/components@1.0.0/dist/index.js"></script>

<!-- 压缩版本 -->
<script type="module" src="https://cdn.jsdelivr.net/npm/@eosjs/components/dist/index.min.js"></script>
```

#### unpkg CDN

```html
<!-- 最新版本 -->
<script type="module" src="https://unpkg.com/@eosjs/components/dist/index.js"></script>

<!-- 指定版本 -->
<script type="module" src="https://unpkg.com/@eosjs/components@1.0.0/dist/index.js"></script>
```

### 方式三：下载源码

```bash
# 克隆仓库
git clone https://github.com/your-org/eos-components.git

# 进入目录
cd eos-components

# 安装依赖
pnpm install

# 构建组件库
pnpm build
```

## 🚀 基础配置

### 1. 注册组件

#### 全量注册（推荐）

```javascript
import { registerComponents } from '@eosjs/components';

// 注册所有组件
registerComponents();
```

#### 按需注册

```javascript
import { 
  registerButton, 
  registerImage, 
  registerCarousel 
} from '@eosjs/components';

// 只注册需要的组件
registerButton();
registerImage();
registerCarousel();
```

### 2. TypeScript 配置

如果使用 TypeScript，需要添加类型声明：

#### 创建类型声明文件

```typescript
// types/eos-components.d.ts
declare namespace JSX {
  interface IntrinsicElements {
    'eos-button': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement>, HTMLElement> & {
      type?: 'default' | 'primary' | 'success' | 'warning' | 'danger';
      size?: 'small' | 'medium' | 'large';
      disabled?: boolean;
      loading?: boolean;
      onEClick?: (event: CustomEvent) => void;
    };
    
    'eos-image': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement>, HTMLElement> & {
      src?: string;
      alt?: string;
      width?: string | number;
      height?: string | number;
      'object-fit'?: 'cover' | 'contain' | 'fill' | 'scale-down' | 'none';
      circle?: boolean;
      responsive?: boolean;
      loading?: 'lazy' | 'eager';
      crossorigin?: 'anonymous' | 'use-credentials';
      blurhash?: string;
      'blurhash-only'?: boolean;
      onLoad?: (event: CustomEvent) => void;
      onError?: (event: CustomEvent) => void;
    };
    
    'eos-carousel': React.DetailedHTMLProps<React.HTMLAttributes<HTMLElement>, HTMLElement> & {
      autoplay?: boolean;
      interval?: string | number;
      loop?: boolean;
      'show-indicators'?: boolean;
      'show-arrows'?: boolean;
      onChange?: (event: CustomEvent) => void;
      onSlideClick?: (event: CustomEvent) => void;
    };
  }
}
```

#### 更新 tsconfig.json

```json
{
  "compilerOptions": {
    "types": ["./types/eos-components.d.ts"]
  },
  "include": [
    "types/**/*"
  ]
}
```

## 🔍 故障排除

### 常见问题

#### 1. 组件不显示

**原因**: 未注册组件或注册时机不对

**解决方案**:
```javascript
// 确保在使用组件前注册
import { registerComponents } from '@eosjs/components';
registerComponents();
```

#### 2. TypeScript 类型错误

**原因**: 缺少类型声明

**解决方案**: 添加类型声明文件（见上文 TypeScript 配置）

#### 3. 样式不生效

**原因**: 未导入样式文件

**解决方案**:
```javascript
import '@eosjs/components/dist/style.css';
```

#### 4. 构建错误

**原因**: 构建工具配置问题

**解决方案**: 检查构建工具配置，确保支持 ES modules
